The terms used across Wrenai and these docs.

| Term | Meaning |
| --- | --- |
| Agent | A saved set of rules with its own budget, which trades on a schedule within its limits |
| Agent key | The key added to your NEAR Intents account by trading access, used to sign agents' trades |
| Budget | The exact token units an agent may use, reserved from your wallet |
| Claim | Sending funds an agent holds, or free private balance, back to your wallet |
| Confidential | Handled inside NEAR Intents' confidential environment, not visible on public chains |
| Guard | The plain-code check every trade passes before it is signed |
| Isolated margin | Perps margin set aside per position, so one position can't draw on another's |
| Jarvis | Wrenai's research chat |
| NEAR Intents | NEAR's intent-based exchange, where your private balance lives |
| Private balance | Your tokens inside NEAR Intents |
| Quote | A priced, expiring offer for one exact trade |
| Quote card | A quote shown in chat or on a market page, which you confirm to trade |
| Reduce-only | An order that can only shrink a position, never open or grow one |
| Slippage | How far the fill may be from the quoted price; your limit sets the minimum you receive |
| TEE | Trusted execution environment: hardware that protects the code running in it |
| Trading account | The account Wrenai holds for public NEAR swaps, backed up by your recovery file |
| Verified reply | A Jarvis reply whose model signature was checked before saving |
| wNEAR | Wrapped NEAR, a token worth one NEAR; claims of NEAR arrive as wNEAR first |
